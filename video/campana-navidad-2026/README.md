# Campaña Navidad 2026 — Elena Velas y Aromas
**Colección "Noche de Luz"** · Eslogan: *"Esta Navidad, regala momentos que iluminan"*

## 1. Investigación de tendencias (resumen)
| Tendencia | Qué significa para Elena |
|---|---|
| Velas escultóricas / "decor-first" | Las velas se compran como objeto decorativo. Nuestros pesebres en relieve y pinos ya encajan. |
| Acabados metalizados (dorado, champagne) para Navidad 2026 | Proponer **Edición Champagne** con los mismos moldes. |
| Formas navideñas reinterpretadas (renos, bastones, árboles) | Familia de Renos y Bosque de Pinos son el núcleo de la colección. |
| "Lujo silencioso": paletas sobrias, minimalismo | Paleta champagne / blanco cálido / verde bosque / vino; fotos sobre fondo oscuro. |
| Personalización | La Sagrada Familia con nombre es el producto de mayor potencial para pedidos por volumen. |
| Mercado Colombia | La temporada decembrina concentra gran parte de la venta anual de velas; la competencia masiva es de velas industriales baratas, así que el diferencial es el diseño artesanal. |

Fuentes: Trend Hunter (velas navideñas escultóricas), Messe Frankfurt / Christmasworld (tendencias 2026, acabados metalizados), Sourcy (velas escultóricas), La República y El Colombiano (temporada decembrina en Colombia). Los artículos son de tipo comercial: tómalos como orientación, no como datos verificados.

- **Caja de regalo:** rojo vino, cinta champagne y etiqueta crema con el logo actual (no se creó otro logo).

## 6. Organización y cómo renderizar
```
public/navidad/originales/   fotos originales (sin modificar)
public/navidad/fotos/        copias redimensionadas para trabajar
public/navidad/recortes/     productos sin fondo (PNG)
public/navidad/referencias/  imágenes de terceros (solo concepto, no se suben al repositorio)
src/Navidad/coleccion.ts     datos de la colección (fuente única)
src/Navidad/index.tsx        comercial (escenas)
src/Navidad/fx.tsx           efectos: llama, nieve, partículas, bokeh, destellos
src/Navidad/catalogo.tsx     páginas del catálogo
```
```bash
npx remotion render src/index.ts Navidad2026-16x9 out/navidad-2026/comercial-navidad-2026-16x9.mp4 --concurrency=1
npx remotion render src/index.ts Navidad2026-9x16 out/navidad-2026/comercial-navidad-2026-9x16.mp4 --concurrency=1
for i in $(seq 0 14); do npx remotion still src/index.ts Catalogo-Navidad out/p$i.png --props="{\"pagina\":$i}" --scale=2; done
```
